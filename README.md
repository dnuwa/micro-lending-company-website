# MicroFund - Micro-Lending Financial Startup

A modern, responsive single-page website for a micro-lending financial startup. Built with Next.js and Tailwind CSS.

## Features

- Smooth scrolling navigation
- Responsive design with mobile-friendly navigation
- Comprehensive sections including:
  - Hero section
  - About Us
  - Services
  - How It Works
  - Testimonials
  - Team section
  - Contact form

## Technologies Used

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- shadcn/ui components

## Getting Started

### Prerequisites

- Node.js (v18.17.0 or newer)
- npm or yarn

### Installation

1. Clone the repository:
   \`\`\`bash
   git clone https://github.com/yourusername/microfund.git
   cd microfund
   \`\`\`

2. Install dependencies:
   \`\`\`bash
   npm install
   # or
   yarn
   \`\`\`

3. Run the development server:
   \`\`\`bash
   npm run dev
   # or
   yarn dev
   \`\`\`

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
